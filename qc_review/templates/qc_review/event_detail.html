How SeisComP picks phases automatically

SeisComP's automatic picking module, scautopick, runs continuously on incoming waveform streams. It works in two stages: a fast energy-based detector that identifies candidate events, followed by an optional re-picker that refines the pick onset.

Stage 1 — STA/LTA Detector

The primary detector applies a classic Short-Term Average / Long-Term Average (STA/LTA) algorithm. The waveform is first bandpass-filtered (default: Butterworth 3rd order, 0.7–2 Hz) to suppress microseismic and instrumental noise. Then two sliding windows compute:

  • STA — short window (~0.5–2 s) sensitive to sudden energy changes
  • LTA — long window (~10–80 s) representing the background noise level

When the STA/LTA ratio exceeds the trigger threshold (default = 3), a preliminary pick is placed at that moment and the stream is flagged for re-picking. The picker resets once the ratio falls below the off-threshold (default = 1.5).

What STA/LTA really measures
The ratio is a measure of energy change, not waveform character. Any sudden energy increase — a P arrival, a noise burst, a teleseismic surface wave, a tectonic tremor, or a passing vehicle — can cross the threshold. The algorithm has no concept of what a P wave is; it only knows that the amplitude got louder.

Stage 2 — Re-pickers (AIC and BK)

Once STA/LTA triggers, scautopick hands the waveform window to a more precise re-picker. Two options are available:

AIC Picker

Akaike, 1974 · Maeda, 1985

Uses the Akaike Information Criterion to find the optimal statistical change-point in a short waveform window. Models the window as two stationary processes (noise before, signal after) and finds the split point that minimises the total AIC.

Best at: Sharp, impulsive P onsets with high SNR.

  • More precise than raw STA/LTA trigger time
  • Works well when noise is stationary
  • Fast, no tuning for individual stations
  • Requires STA/LTA to trigger first — misses very small events
  • Sensitive to non-stationary noise (e.g., glitches, spikes)
  • Only picks P; needs separate module for S

BK Picker (Baer-Kradolfer)

Baer & Kradolfer, 1987

Computes a characteristic function based on the envelope of a bandpass-filtered signal, using amplitude thresholds rather than statistical information criteria. Designed specifically for local and regional seismicity.

Best at: Moderate SNR local events, robust in broadband noise.

  • Robust against emergent onsets common in local events
  • Less sensitive to high-frequency spikes than AIC
  • Configurable per station via frequency bands and thresholds
  • Requires careful tuning per network / magnitude range
  • Threshold-based — struggles when noise character changes
  • Only picks P by design

Stage 3 — S-phase picker (S-L2)

For S-phase picking, scautopick uses the S-L2 spicker, which exploits the polarization difference between P and S waves: P energy is concentrated on the vertical component (Z), while S energy dominates the horizontal components (N and E). The L2 norm of the horizontal components is computed after the P arrival, and the S onset is estimated from the peak of this horizontal energy envelope.

S-phase limitation
S-L2 can only run after a P pick exists, and is sensitive to the assumed P–S velocity ratio. It works best for simple, clear local events. For noisy records, low-magnitude events, or emergent S arrivals, it often misses or places the pick on the S-wave coda rather than the true onset.

How EQTransformer picks phases

EQTransformer (Mousavi et al., 2020) is a deep-learning model built on a transformer + encoder-decoder architecture trained on millions of three-component seismic waveform examples from global networks. Unlike threshold-based methods, it learns representations — the characteristic shape, frequency content, and polarization signature of P and S arrivals — directly from labelled data.

Architecture in plain terms

A fixed-length three-component window (60 s at 100 Hz = 6,000 samples per channel) is fed through:

  1. Encoder — seven residual convolutional blocks with LSTM layers extract progressively abstract temporal features from all three components simultaneously.
  2. Transformer — a self-attention mechanism captures long-range dependencies across the full window, connecting the noise character before the P arrival with the signal character after.
  3. Three decoder heads — one each for detection probability, P-phase probability, and S-phase probability, running in parallel on the encoded representation.

The outputs are three continuous time series of probabilities (0–1), one per sample. A pick is placed where the P-head or S-head exceeds the configured threshold (default 0.3), at the peak of each probability spike.

EQTransformer via SeisBench

Mousavi et al., 2020 · SeisBench: Woollam et al., 2022

Trained on 1.2 million waveform examples from the STEAD dataset, covering earthquakes from magnitude 0.1 to 7.9, distances from local to teleseismic, and SNR from very clean to barely detectable.

Best at: Low-to-moderate SNR, emergent onsets, simultaneous P and S, noisy station environments.

  • Picks P and S jointly in one forward pass — no need to chain separate algorithms
  • Returns a calibrated probability score, not just a time — gives you confidence information
  • Trained on diverse noise conditions; generalises well to different network types
  • No threshold tuning per station — a single probability cutoff works globally
  • Sees all three components simultaneously — uses S-wave polarization implicitly
  • GPU-batched: 20 stations processed in ~1 second on RTX 2000 Ada
  • Requires PyTorch and ~150 MB model weights (downloaded once, cached)
  • Fixed 60-second input window — very long codas or overlapping events need special handling
  • May underperform on very unusual local noise conditions not well-represented in STEAD
  • Black box — harder to reason about why it placed a pick where it did
  • Requires GPU for fast batch processing (CPU works but is ~10× slower)

Why EQTransformer is the right QC second opinion

A second opinion is only useful if it is independent. If you run STA/LTA a second time, or AIC with slightly different parameters, you will almost always get the same answer — because the underlying question is still "where does the energy change?" If the analyst placed P on a noise burst, a second STA/LTA pass will place it there too.

The independence principle
EQTransformer disagrees with the analyst through a fundamentally different mechanism. It does not measure energy onset. It recognises the shape of a P or S arrival — the characteristic frequency sweep, the polarity change on the vertical component, the expected S/P amplitude ratio. When it disagrees, it is because it saw something in the waveform morphology that conflicts with the pick position. That is meaningful disagreement worth investigating.

Three concrete cases where EQT catches analyst errors

Case 1 — Noise spike trigger

A noise burst (glitch, teleseismic phase, cultural noise) causes STA/LTA to trigger early. The analyst, seeing the trigger, places P on the spike. EQTransformer, looking at the full waveform, recognises that the spike does not have the characteristic frequency content of a P arrival from a local earthquake and places its pick several seconds later where the true P onset occurs. Δt typically > 1 s → red flag.

Case 2 — Emergent P onset

For deeper or more distant events, the P arrival builds slowly rather than arriving impulsively. STA/LTA (and human analysts looking for the "obvious" onset) tend to place P too late, at the point where energy is clearly above noise rather than at the true first motion. EQTransformer, trained on emergent arrivals, picks closer to the true onset. Δt typically 0.2–0.8 s earlier → yellow or green flag.

Case 3 — Analyst P/S confusion

For a short P-S interval (near station, local event), an analyst unfamiliar with the station's typical waveform may place the P pick on an S arrival or vice versa. EQTransformer uses three-component polarization information implicitly — P dominates the Z component, S dominates N/E — and is unlikely to confuse the two for clear records. Δt large and inconsistent with nearby stations → red flag, check phase label.

Case 4 — Cycle skipping

On low-frequency records (regional/teleseismic), an analyst may pick one full cycle (period) late relative to the true onset — a common error on 10–15 s period surface waves. EQTransformer, having seen this pattern in training data, is less prone to cycle-skipping for the P phase. Δt close to one dominant period → red flag, check waveform frequency content.

Three cases where EQT should be treated with caution

Very local microseismicity (<10 km)

P-S separation may be less than 2 seconds. EQTransformer's 60-second window was trained predominantly on events with longer P-S. Its S pick on very nearby events is less reliable. Trust the analyst's S pick more for Δ < 0.1°.

Highly unusual local noise

If your station has a distinctive noise source (harbour waves, factory machinery, geothermal tremor) not well-represented in the STEAD training data, EQTransformer may produce false picks with high probability scores. A station with systematic high ΔP across many events should be investigated — it may need the model fine-tuned on local noise.

Overlapping events

If a second earthquake occurs within the 60-second processing window of the first, EQTransformer may pick phases from both events on the same trace. The analyst, with contextual awareness of the seismic sequence, is better positioned to identify and separate overlapping events.

Teleseismic phases (depth phases)

For teleseismic events, depth phases (pP, sP) arrive shortly after the direct P and can be mistaken for it. EQTransformer is trained primarily on single-station local/regional picking and may not correctly distinguish P from pP for deep teleseismic events. For events with Δ > 30°, use EQT picks as a rough reference only.

Reading the QC flags in this system

Each station is assigned a QC flag based on the worst absolute residual between the analyst's pick and EQTransformer's pick, across both P and S.

Green — |Δt| < 0.5 s
Yellow — 0.5 s ≤ |Δt| < 1.5 s
Red — |Δt| ≥ 1.5 s

These thresholds are calibrated for local and regional events on short-period instruments (SH channels, 100 Hz). For teleseismic events, a yellow flag at 1.5 s is not necessarily alarming — EQTransformer's absolute accuracy degrades with distance. Use the distance class shown on each station card to contextualise the flag.

Practical workflow for junior analysts
1. Open the Pick Comparison tab first. Sort by ΔP to find the worst discrepancies. 2. For any red or yellow station, click to the Waveforms tab and scroll to that station. 3. Look at the annotation panel: does EQT's dashed line land on a clearer phase onset than the analyst's solid line? 4. If yes → mark as "Needs re-pick" and leave a note explaining which phase and direction. 5. If no (EQT seems confused) → mark as "Accept analyst pick" with a note like "EQT appears to have triggered on noise burst." 6. After the senior analyst reviews your notes and re-commits, the new run will appear in the run dropdown and you can compare run #1 vs run #2 to see how the picks changed.
